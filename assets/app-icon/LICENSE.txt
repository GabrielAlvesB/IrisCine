IrisCine app icon (filmcraft.svg and every file derived from it in this directory:
filmcraft-small.svg, filmcraft-1024.png, filmcraft-macos-512.png, filmcraft.icns, filmcraft.ico,
hicolor/, and apps/filmcraft-web/web/favicon.png).

Original artwork made for IrisCine by Gabriel Alves Tech: an open clapperboard with a play
triangle, drawn directly as SVG. No third-party material. It replaces FilmCraft's icon, which
IrisCine does not use.

The icon is an Iris brand asset owned by Gabriel Alves Tech. It is not covered by IrisCine's code
license (MIT OR Apache-2.0); like the Iris name, it identifies the Iris ecosystem.

Regenerate the derived files with packaging/icons.sh.
